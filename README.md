# G3 Architects Website

A modern, responsive landing page built for a fictional architecture firm — **G3 Architects**. This project is ideal for learning and practicing HTML and CSS layout design.

## 🌐 Live Site

👉 [View Live Website](https://khalidhossain5000.github.io/my-g3-architects-full-website/)

---

## 🎯 Features

- Clean and professional layout
- Fully responsive design for all screen sizes
- Sections include Hero, Features, Services, Facts, and Footer
- Smooth typography and color palette
- Reusable and well-structured HTML & CSS code

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox & CSS Grid
- Google Fonts (Poppins)
